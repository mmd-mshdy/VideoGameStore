پروژه مدیریت و خرید بازی های ویدیویی با Clean architecture و DDD(Domain Driven Design)
اعضای گروه و وظایف آنان:
محمدرضا مشهدی حسین : تعریف کردن business logic ها و Core business ideas . اضافه کردن Value object  ها و Smart enums و Aggregate root در لایه Domain با پیروی از DDD . استفاده از result pattern برای error handling در لایه domain .اضافه کردن CQRS  و تعریف کردن هندلر ها با استفاده از Mediator .  
مهدی فاتحی : پیاده سازی repository pattern  در لایه REpository . اضافه کردن Unit of Work و Configuration برای Database .اضافه کردن سرویس Log و سرویس Monitoring با استفاده از لایبرری  Open telemetry . اضافه کردن Validation با استفاده از Fluent Validatio اضافه کردن caching به برنامه از نوع (Hybrid caching) 
مهیار محمدی : اضافه کردن Authentication با استفاده از jwt و Authorization با پیروی از Role-based Authorization و گسترش دادن Controller  ها و endpoint ها .
